# 新接龍（Windows 7 風格）設計

## 目標

- 以前端技術重現 Windows 7 / Vista 的新接龍（FreeCell）。
- 局號 1～1,000,000，使用微軟 LCG 發牌演算法，同一局號與 Windows 牌局相同。
- 正式專案、可部署為純靜態網站。

## 技術

Vue 3（Composition API、SFC）+ Vite + JavaScript（JSDoc 註解）、Pinia、VueUse、Vitest + @vue/test-utils。

## 發牌演算法

- `state = (214013 * state + 2531011) mod 2^31`，`rand = state >> 16`，種子 = 局號。
- 牌堆依 A..K、每個點數內 梅花／方塊／紅心／黑桃 排序（index = rank*4 + suit）。
- 反覆取 `rand % 剩餘張數`，與最後一張交換後發出最後一張；依序左到右逐列發到 8 欄。
- 驗證：Rosetta Code 公布的 #1、#617 牌局。大於 32000 的局號沿用同一演算法（FreeCell Pro 等第三方實作一致；未取得微軟官方文件）。

## 規則（同 Win7）

- 4 個暫存格、4 個回收區、8 欄。
- 一次可移動張數 = (空暫存格 + 1) × 2^(空欄數)；目的地是空欄時，空欄數不計目的地本身。
- 拖曳多張到空欄時，詢問「移動整列」或「只移動一張」。
- 雙擊：能進回收區就進回收區，否則進暫存格。
- 點選後再點目的地也可移動。
- 安全自動收牌：A、2 一律收；其他牌在兩個異色花色的回收區都已到 rank-1 時收。
- 無限 Undo；一次使用者移動與隨之而來的自動收牌算一步。
- 沒有合法移動時提示，可選擇復原、重新開始或新局。

## 功能

- 選單：遊戲（新局 F2、重新開始、選擇遊戲 F3、統計資料 F4、選項 F5、變更外觀 F7）、說明（關於）；Ctrl+Z 復原、H 提示。
- 狀態列：局號、時間、移動次數。
- 網址 `?game=N` 直接開啟該局；開局時同步網址。
- 統計：已玩、勝場、勝率、最長連勝、最長連敗、目前連續；進行中的局放棄（新局／重新開始／選擇遊戲／拒絕續玩）算輸。
- 提示：亮出一個建議移動的牌與目的地；優先回收區，避免立即抵銷上一步。
- 自動存檔：每步存 localStorage（局號＋移動紀錄＋時間），重新開啟時詢問是否續玩。
- 外觀：牌桌背景、牌背圖案；選項：音效、動畫、提示有無合法移動。

## 架構

- `src/core/`：純 JS，不依賴 Vue。`cards`、`deal`、`rules`（狀態、合法性、套用移動、自動收牌）、`hint`。
- `src/stores/`：`game`（目前局、undo 堆疊、計時、存檔）、`stats`、`settings`。
- `src/components/`：`MenuBar`、`GameBoard`（版面、拖曳、動畫）、`PlayingCard`（SVG 自繪牌面，不使用微軟圖檔）、`StatusBar`、各對話框。
- 牌以絕對定位＋CSS transform 呈現，靠 transition 做移動動畫；拖曳時關閉 transition 直接跟隨 pointer。

## 測試

- core：發牌對照已知牌局、移動規則、張數上限、自動收牌、勝利判定、提示。
- stores：undo、存檔／續玩重播、統計計算。
- 元件：主畫面掛載與基本互動煙霧測試。
